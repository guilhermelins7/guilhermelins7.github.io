# Portfólio — Guilherme Lins dos Santos

Bem-vindo ao repositório da nova versão do meu portfólio pessoal. O projeto reúne minha trajetória, experiências profissionais, trabalhos selecionados, competências técnicas, certificações e canais de contato em uma interface moderna e responsiva.

**[Acesse o portfólio](https://guilhermelins7.github.io)**

## Tecnologias utilizadas

- **React 19** e **TypeScript** — construção da interface com componentes tipados e reutilizáveis.
- **Vite** — ambiente de desenvolvimento e geração da versão de produção.
- **Tailwind CSS v4** — estilização, responsividade e definição dos temas claro e escuro.
- **React Icons** e **Material Icons** — ícones da interface.
- **GitHub Pages** — hospedagem do site estático.

## Estrutura do projeto

```text
.
├── public/                 # Ícones e arquivos estáticos públicos
├── src/
│   ├── assets/             # Foto de perfil e logos das empresas/instituições
│   ├── components/         # Componentes reutilizáveis, como cards e navegação
│   ├── sections/           # Seções principais do portfólio
│   ├── App.tsx             # Composição da página
│   ├── index.css           # Tema, estilos globais e animações
│   └── main.tsx            # Ponto de entrada da aplicação
├── index.html              # Documento HTML base
├── package.json            # Dependências e comandos do projeto
└── vite.config.ts          # Configuração do Vite e do Tailwind CSS
```

## Funcionalidades

O portfólio foi desenvolvido para apresentar informações profissionais de forma clara, agradável e consistente em diferentes dispositivos.

### 1. Design responsivo

- Layout adaptado para celulares, tablets e desktops.
- Componentes, grids e tipografia ajustados para diferentes tamanhos de tela.

### 2. Navegação intuitiva

- Navegação por âncoras entre as seções da página.
- Indicação visual da seção ativa conforme a rolagem.
- Menu compacto para dispositivos móveis, com fechamento por clique externo ou pela tecla `Esc`.

### 3. Tema claro e escuro

- Alternância entre temas claro e escuro.
- Preferência inicial baseada no sistema operacional e escolha persistida no navegador.

### 4. Experiência e trabalhos selecionados

- Linha do tempo com experiências profissionais e tecnologias utilizadas em cada atuação.
- Projetos e sites institucionais apresentados em cards com links para as páginas ou repositórios correspondentes.

### 5. Skills e certificações

- Competências organizadas por área de atuação.
- Lista expansível de certificações, permitindo explorar todas as credenciais sem sobrecarregar a página inicial.

### 6. Contato e presença profissional

- Links para GitHub, LinkedIn e currículo.
- Atalhos para contato por e-mail e telefone.

## Como executar localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) 20 ou superior
- npm

### Instalação

```bash
git clone https://github.com/guilhermelins7/guilhermelins7.github.io.git
cd guilhermelins7.github.io
npm install
```

### Desenvolvimento

```bash
npm run dev
```

O Vite exibirá no terminal o endereço local para visualizar a aplicação.

### Gerar a versão de produção

```bash
npm run build
```

Os arquivos otimizados serão gerados na pasta `dist/`.

### Verificar o código

```bash
npm run lint
```
